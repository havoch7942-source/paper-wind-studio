# 종이와 바람 · Paper Wind Studio

[English](README.md) · [웹 편집기 열기](https://paper-wind-studio-yuran.havoch7942.chatgpt.site)

이미지 위에 접힘 축과 고정점을 그려 자연풍에 펄럭이는 종이를 만드는 웹 편집기입니다. 언어 메뉴에서 **한국어 / English**를 전환할 수 있으며 선택은 브라우저에 저장됩니다.

## 편집하기

1. PNG, JPEG, WebP 이미지를 불러옵니다. 찢어진 가장자리는 투명 PNG로 준비합니다.
2. 녹색 **산접기** 또는 파란색 **골접기**를 고르고 이미지 위를 드래그합니다.
3. **고정점**을 선택하고 종이를 붙잡을 위치를 찍습니다.
4. 바람 세기, 돌풍 변화, 접힘 저항, 바람 방향, 전체 흔들림을 조절합니다.
5. **작업 저장**으로 이미지와 설정을 JSON에 저장하고 **작업 열기**로 복원합니다.

이미지와 작업 파일은 브라우저 안에서 처리합니다. 업로드 서버는 없습니다.

## Godot 4 게임에 넣기

1. **Godot용 내보내기**를 누릅니다.
2. ZIP을 풀고 `paper_wind` 폴더 전체를 Godot 프로젝트의 `res://` 아래로 복사합니다.
3. 이미지 가져오기가 끝나면 `paper_wind/demo.tscn`을 열고 **F6**으로 시험합니다.
4. 게임 장면에 `paper_wind/paper_wind.tscn`을 인스턴스하고 위치·회전·크기를 맞춥니다.
5. Inspector에서 바람·흔들림 속성을 조절합니다. `Playing`을 끄면 갱신을 멈춥니다.

ZIP에는 이미지, 실행 스크립트, 내장 설정, 종이 장면, 테스트 장면, 한글·영문 사용 설명과 실행 코드 라이선스가 들어갑니다. 현재 편집 설정으로 처음부터 재생합니다. 나중에 웹에서 수정하려면 작업 JSON도 별도로 저장하세요.

Godot 4.7.2에서 실행과 렌더링을 확인했습니다. 웹과 Godot의 고정 600회 계산 중 네 시점의 위치 오차는 0.001 Godot 단위 미만이었습니다. 조명과 재질 표현은 엔진에 따라 다릅니다. Godot 3은 지원하지 않습니다.

## 내 컴퓨터에서 실행하기

Node.js를 설치하고 저장소를 내려받은 뒤 루트 폴더에서 실행합니다.

```sh
node serve.mjs
```

<http://127.0.0.1:8874>를 엽니다. npm 설치나 빌드 과정은 없습니다. `index.html`을 파일로 직접 열면 ES 모듈이 작동하지 않으므로 HTTP 서버를 사용해야 합니다. `dist/` 내용을 일반 정적 호스팅에 올려도 됩니다.

```sh
node verify-model.mjs
node verify-browser-modules.mjs
```

## 모델과 제한

- 면은 단단한 패널로 유지하고 접힘 축에서 회전합니다. 일반적인 천 물리 시뮬레이션은 아닙니다.
- 짧게 그린 선도 종이 경계까지 연장된 축으로 계산합니다. 면 내부에서 끝나는 국소 접힘은 지원하지 않습니다.
- 평행한 접힘은 함께 움직일 수 있지만 교차 방향은 번갈아 움직입니다.
- 접힘 양쪽에 고정점이 있으면 해당 축을 고정합니다. 전체 흔들림은 고정점 1개 이하에서만 적용합니다.
- 자체 충돌, 종이 두께, 찢어짐, 게임플레이 충돌은 지원하지 않습니다.
- Godot 장면은 재생 중인 인스턴스마다 계산과 메시 갱신을 수행합니다. 다수 배치 성능은 검증하지 않았습니다.

`dist/paper-model.js`는 면 분할과 힌지 회전, `dist/app.js`는 편집기와 바람, `dist/i18n.js`는 UI 번역, `dist/godot-export.js`는 Godot ZIP 생성을 담당합니다. `dist/godot/paper_wind.gd`는 웹과 같은 고정 60Hz 계산을 사용합니다.
